04 / A LITTLE ABOUT THE MODEL

How does it work?

Where did the data come from?

Actually, our model uses the Employment Scam Aegean Dataset (EMSCAD), which contains historical job advertisements that were collected between 2012 and 2014.

How does the model work?

We use TF-IDF to turn job-posting text into numerical features. Logistic Regression then learns patterns that can help distinguish fraudulent postings from legitimate ones.

What does the score mean?

The score shows how strongly the model associates a posting with the fraudulent class. It is not a verified probability of fraud.

What should you keep in mind?

The dataset contains older job advertisements, so the model may not recognise every type of scam seen today. It cannot verify an employer or guarantee that a job offer is genuine.
